# Reportes de vigilancia

Un archivo por día, `AAAA-MM-DD.md`, que escribe la skill `vigilar-plugins`. Cada revisión del día se agrega como
una sección `## HH:MM` con los hallazgos clasificados y lo que se hizo con cada uno. Es el estado observado, no una
bitácora de cambios: los cambios van en `plugins/<x>/docs/bitacora/versiones/`.
