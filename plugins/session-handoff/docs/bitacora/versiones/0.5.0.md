# 0.5.0 — El handoff funciona en Codex, Antigravity y OpenCode

- **Fecha**: 2026-11-20 · **Commit**: ver el tag `session-handoff-v0.5.0` · **Tipo**: feature
- **Spec**: [001 · plugins multi-agente](https://github.com/bypabloc/agent-plugins/tree/synapse-v1.7.0/docs/specs/001-plugins-multi-agente)

## Síntoma

En 0.4.5 el lote de klinikae pasó a Codex y el handoff solo protegía a la sesión de Claude Code. El otro agente no
recibía el trabajo al iniciar, podía cerrar el turno con un `Next step` pendiente y nadie le pedía los hashes.

## Cambio

- Núcleo sin cambios de lógica. `writeText(tools)` nombra las herramientas de archivos de cada host; el texto de
  Claude Code es idéntico.
- `hooks/actions.ts` hace lo mismo que `register.tsx` para los demás hosts: inicio, prompt, post-tool, `Stop` (mismo
  orden: hashes, sesión que tomó el trabajo y `stopDecision`), pregunta y recordatorio. El estado va en
  `tmp/handoff/.state/<sesión>.json`.
- **Codex y Antigravity**: `dist/hook.mjs`, un bundle de `cli/cli.ts` que corre con `node` ≥ 20 y siempre sale con 0.
  - Codex: `additionalContext` (en `PostToolUse` nunca `block`, porque ahí reemplaza la salida del comando),
    presupuesto de 8000 caracteres para el handoff e idempotencia de `Stop` por `turn_id`.
  - Antigravity: `injectSteps` al iniciar y en cada invocación, `Stop` con `continue`, y los commits de la sesión
    desde el HEAD inicial, porque Antigravity no da la salida de las tools.
- **OpenCode V2**: plugin en proceso (`adapters/opencode/index.ts`) sobre `context`, `execute.before/after` y
  `session.execution.succeeded`.

## Prueba

- `bun test tests/cli` (55 tests con fixtures reales) y `claude plugin test .` (68 tests, sin cambios).
- `tests/e2e/hosts_e2e.py`:
  - Antigravity: inyecta, bloquea el `Stop` y el agente sigue con el `Next step` (creó `LISTO.txt`).
  - OpenCode (modelo falso): inyecta y bloquea.
  - Codex: frenado el día del release por el límite de uso de la cuenta.

## Lección

Lo que hacía portable al plugin ya estaba hecho: el núcleo puro con `Io`. Portarlo fue escribir un cableado por host.
Lo que no se portó (compactar sin resumen, banda, spinner) depende de la API de mods y ningún otro host la tiene.
